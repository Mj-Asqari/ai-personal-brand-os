# Confidentiality Policy

## ۴ سطح

| سطح | تعریف | مثال | انتشار |
|---|---|---|---|
| `public` | تجربه شخصی، بدون ارجاع سازمانی | over-engineering، درس یادگیری | آزاد |
| `anonymized` | عدد و ساختار بدون نام | ۷۰۰۰ مشتری، ۸ طبقه، ۹۷٪ دقت | مجاز |
| `internal` | اشاره به پویایی داخلی سازمان | اختلاف بین تیم‌ها | ممنوع |
| `restricted` | داده مشتری، فروش، کارکنان، برند | نام مشتری، رقم فروش | هرگز |

## قوانین ناشناس‌سازی
- نام مشتری، رقیب، برند، SKU → حذف کامل
- عدد مطلق فروش → حذف یا تبدیل به نسبت
- عدد ساختاری (تعداد رکورد، دقت مدل، تعداد طبقه) → مجاز
- نام همکار و مدیر → هرگز
