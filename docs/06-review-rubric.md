# Review Rubric

## تست «بوی تجربه» — گیت اجباری
حداقل ۲ از ۴:
- [ ] جزئیات اجرای واقعی
- [ ] محدودیت یا trade-off
- [ ] خطا/شکست و اصلاح آن
- [ ] عدد یا نتیجه مشخص

نمره <۲ → rejected. برنمی‌گردد به Writer، برمی‌گردد به Interview.

## چهار pass
1. Editorial — لحن، ساختار، بدون بوی ترجمه
2. Fact-check — هر ادعا به تجربه یا citation وصل
3. Confidentiality — طبق ۰۲
4. بوی تجربه — بالا

## پست بد (reject فوری)
- «AI انقلاب کرد»
- لیست N ابزار بدون تجربه
- متن ترجمه‌ای / ChatGPT‌مانند
- ادعای کلی بدون جزئیات اجرا

## CTA
ملایم و مشاوره‌محور. فروش مستقیم و التماس engagement ممنوع.
